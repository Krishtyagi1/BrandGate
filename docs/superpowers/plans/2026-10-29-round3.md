# Round 3 implementation plan

> Execute inline using superpowers:executing-plans, test-driven-development and verification-before-completion. User directed execution with “start wprking” after the three-feature specification.

**Goal:** Deliver advisory visual review, a source-grounded read-only follow-up assistant, and recurrence/guideline-gap insights.

**Architecture:** Extend the existing FastAPI/PostgreSQL/Next.js workflow. Reviews and answers use immutable approved knowledge snapshots. Deterministic sampled-colour contrast and palette checks run locally; optional vision retains existing free-only privacy constraints. The assistant is extractive, with AG-UI messages and no model tools or business mutation capability. Analytics retain observed findings across revisions in a bounded reporting period, counting a draft once per type/status.

**Spec:** The user's three requirements and revised wording in this chat; INKLOOM_CODEX_IMPLEMENTATION_PLAN.md, phase 6. Existing build authorisation is recorded in IMPLEMENTATION_STATUS.md; current user explicitly directs this implementation. Do not infer or claim official Round 3 dates.

## Global constraints

- No automatic approval/publication; visual observations remain advisory.
- Preserve organisation isolation, creator access limits, saved revision/source pins and existing provider consent.
- Never lower privacy or use paid vision without explicit authorisation. No actual-person photos in fixtures.
- Keep the white three-tab interface; insights belong under Tracking.
- No live accuracy claim from synthetic transport tests. Clearly report unavailable routes and unrun image comparisons.
- Work in this checkout; preserve prior work and do not deploy or push.

## Review focus

1. Stale revisions or changed sources: assistant declines until recheck.
2. Forged/cross-organisation finding and citation IDs: refuse or abstain.
3. Repeated reviews: count each draft once; include incomplete coverage honestly.
4. Transparent/anti-aliased samples: contrast must not claim whole-image compliance.
5. Questions containing instructions: no authority changes or ungrounded answers.
